# WaNet frozen-model diagnostics

Generated by `wanet_diagnostics.py`; the formal CTR CSVs, tables, checkpoints,
and training code were not modified.  Checkpoint hashes, domains, and row
counts are recorded in `manifest.json`.  `bootstrap_summary.csv` contains
2,000 paired, true-class-stratified bootstrap replicates (seed 2333).

## Completed

- Four requested ResNet-18 WaNet configurations were evaluated on paired clean
  and triggered inputs.
- STL-10 96-to-32 resize variants (bicubic/bilinear, antialias on/off) were
  evaluated with the same trigger grid.
- Source-domain 2x and 4x bicubic resampling was evaluated.
- Ten independent smooth warp fields and ten correct-field-plus-random-noise
  fields were evaluated.

## Current evidence

- Official STL preprocessing (bicubic, no antialias) gives ASR 0.0416 for the
  CIFAR-10 1%, s=0.8 model.  The same images with antialiasing give ASR 0.5636
  (bicubic) and 0.7372 (bilinear), while the model and trigger are unchanged.
- Source resampling alone raises target-class prediction rates for Tiny models
  (about 0.36--0.43 for the 1% models and about 0.995 for the 5%, s=0.4
  model), accompanied by severe clean-accuracy collapse.  This demonstrates
  sensitivity to resampling, but is not by itself a WaNet-specific causal
  proof.
- The exact saved field is highly effective, but independent smooth fields can
  also produce high ASR on some models.  Random full-resolution perturbations
  added to the correct field are generally low-ASR.  This separates the
  tested field families; it does not identify a training-time cause.

## Pending limitations

- The original ImageNetV2 images referenced by the construction manifest are
  unavailable.  The target directory contains already-downsampled 64x64 JPEGs,
  so the ImageNetV2 resize-kernel experiment was not substituted with an
  invalid upsample/downsample procedure.
- BadNets and Blend control models and the ImageNetV2 resize experiment remain
  pending.  Their absence is recorded here rather than treated as a negative
  result.
